# Code outside this repo: staper

The Stape codebase spans many `stape-io/*` repos, searchable through the **staper MCP**; its tool descriptions say which tool fits which question.

- **Ground, don't recall.** Before stating how anything in `stape-io/*` outside this repo behaves, look it up in staper. An empty result is an answer: say so instead of guessing.
- **Let the hits name the repo.** Search without a `repos` filter; every hit carries its `repo`. Add a `repos` filter only with a repo a hit in this conversation named.
- **Cite.** Every code claim points at `<repo>/<path>`; every architecture claim keeps its confidence (`verified` / `inferred` / `unknown`).
- **Public content is terminology.** Use `content:*` hits (blog, documentation, knowledgebase) for wording only; take behaviour from code.
