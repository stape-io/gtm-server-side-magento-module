# Domain docs

Before exploring code, read the repo's glossary (`GLOSSARY.md` at the root, or the ones `GLOSSARY-MAP.md` points to for the area) and the ADRs that touch the area, in the root `docs/adr/` and, in a multi-context repo, the context's own `docs/adr/`. Missing files are normal: `/stape-dev:domain-modeling` creates them when a term or decision is first resolved. Name concepts with the glossary's terms, and when work contradicts an ADR, say so and why it is worth reopening.
